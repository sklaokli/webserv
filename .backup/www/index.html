📋 42 Project Specification Compliance

  • Language: C++98 compliant (-Wall -Wextra -Werror -std=c++98 -pedantic).
  • Multiplexer: Single non-blocking epoll event loop monitoring listeners, clients, and CGI pipes.
  • No Read/Write without Epoll: Zero operations performed without prior readiness.
  • Errno Prohibition: errno is never inspected to determine socket state after read/write.
  • Fork Usage: Strictly restricted to CGI execution.
  • Leak-Free: 0 memory leaks, 0 open FD leaks verified with Valgrind.
